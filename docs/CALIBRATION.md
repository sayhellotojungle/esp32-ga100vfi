# 时序与遥测数据限制

本页说明固件报告的时间与遥测字段能证明什么、不能证明什么。保留此文件名供旧链接使用；它不提供新的参数搜索或故障注入优化步骤。

## 1. 时间轴的限制

毛刺时间轴由软件时间表执行。阻塞式 I²C、驱动调用和调度都会造成迟到，这些误差无法通过任务归并消除。

- `slip` 报告时间表步骤开始执行时的最大迟到量；`reset_slip` 报告实际复位释放操作的时间戳与计划零点的差。
- 两者记录的都是 MCU 侧软件时间，不直接测量外部引脚的模拟边沿、供电变化或控制器响应时间。
- 本版未采用独立硬件定时器来保证复位时刻，因此任何数值都不能承诺微秒级确定性时序。

## 2. 遥测数据

毛刺尝试期间固件按时间轴用 PMBus 直读控制器 VOUT（`vs t=… v=…` 行），并在结束行前输出 STATUS_WORD、CML 与 E1 的读取结果。这些都是控制器报告的状态字，不是波形：

| 信息 | 可以说明 | 不能单独证明 |
|---|---|---|
| `writes_failed` | 软件是否观察到关键写操作失败 | 命令已产生预期外部物理效果 |
| `diag_ok` | 尝试后的相关诊断读取是否完成 | 全部设备状态正常 |
| `vout_uv` / STATUS_WORD | 读到的控制器状态位 | 确切波形、持续时间或故障原因 |
| `vs` 采样行 | 采样时刻控制器上报的 VOUT 读数 | 两次采样之间发生的变化 |
| 自动流程 verdict | 对应轮次的一组软件检查结果 | 未检查的寄存器、链路及外部电气状态 |

如需波形级观测，请在电源轨上用示波器另行测量；本固件不在板上做模拟采样。

## 3. 验证范围

本页字段含义基于离线源码与替身回归（逐版结果见 [../CHANGELOG.zh-CN.md](../CHANGELOG.zh-CN.md)）。档案波形几何（`3 × 222 µs`、`gap 150 µs`、`td=-40 vr=750 tr=-20`、`delay=54`）已在实卡命中 Goldilocks 并完成 FF 烧写闭环（见 [UNLOCK_AND_POISON.md](UNLOCK_AND_POISON.md) §六）；板上未做模拟采样，波形级观测需外部示波器。历史项目中的固定延迟、标称样率与成功率描述不作为本版验证依据。
